Esta página reúne los elementos HTML que utiliza el sitio. De cada uno se muestra cómo funciona, su código y, cuando hace falta, una nota sobre su uso.

Texto

Encabezados h1 a h6

Los encabezados organizan el contenido en niveles jerárquicos y permiten identificar los temas y subtemas de una página.

Encabezado de nivel 4

Encabezado de nivel 5
Encabezado de nivel 6
<h4>Encabezado de nivel 4</h4>
<h5>Encabezado de nivel 5</h5>
<h6>Encabezado de nivel 6</h6>

Buena práctica: mantener una jerarquía lógica de encabezados. Esta demostración comienza en h4 porque está dentro de un artículo cuya jerarquía ya utiliza h3.

Párrafo y salto de línea p y br

El elemento p agrupa un bloque de texto. El elemento br introduce un salto de línea cuando este forma parte del contenido, como en una dirección postal.

Atendemos perros, gatos y animales pequeños.

Clínica Veterinaria ConSentidos
Avenida Central, Santiago de Veraguas
Panamá 

<p>Atendemos perros, gatos y animales pequeños.</p>

<p>
  Clínica Veterinaria ConSentidos<br>
  Avenida Central, Santiago de Veraguas<br>
  Panamá
</p>

Énfasis strong, em y mark

Estos elementos comunican distintos significados: importancia, énfasis en la entonación y resaltado de un texto relevante.

La vacuna antirrábica es obligatoria cada año.

Tu mascota sí necesita agua fresca, aunque no la pida.

Recuerda traer el carné de vacunación a la consulta. 

<p>La vacuna antirrábica es
  <strong>obligatoria</strong> cada año.</p>

<p>Tu mascota <em>sí</em> necesita agua fresca,
  aunque no la pida.</p>

<p>Recuerda traer el
  <mark>carné de vacunación</mark> a la consulta.</p>

Código pre y code

code representa fragmentos de código dentro de un texto. pre muestra bloques preformateados y conserva los espacios y saltos de línea.

Para mostrar una imagen se utiliza <img>. 

<p>
  Bienvenido a ConSentidos.
</p>
<p>Para mostrar una imagen se utiliza
  <code>&lt;img&gt;</code>.</p>

<pre><code>&lt;p&gt;
  Bienvenido a ConSentidos.
&lt;/p&gt;</code></pre>

Fecha y hora time

El elemento time representa fechas y horas. Su atributo datetime proporciona un valor que las máquinas pueden interpretar.

Próxima jornada de vacunación: 5 de diciembre de 2026 . 

<p>
  Próxima jornada de vacunación:
  <time datetime="2026-12-05">
    5 de diciembre de 2026
  </time>.
</p>

Listas

Lista ordenada ol

Una lista ordenada presenta elementos cuyo orden importa, por ejemplo, los pasos de un procedimiento.

  1. Registro en recepción.
  2. Triaje.
    1. Peso en báscula.
    2. Temperatura.
  3. Consulta con el veterinario.
  4. Indicaciones y próxima cita.
<ol>
  <li>Registro en recepción.</li>
  <li>
    Triaje.
    <ol type="a">
      <li>Peso en báscula.</li>
      <li>Temperatura.</li>
    </ol>
  </li>
  <li>Consulta con el veterinario.</li>
  <li>Indicaciones y próxima cita.</li>
</ol>

Importante: la lista anidada debe estar dentro de un elemento li de la lista principal.

Lista no ordenada ul

Una lista no ordenada agrupa elementos cuando el orden en que aparecen no es importante.

  • Revisión general.
  • Control de peso.
  • Orientación nutricional.
  • Recomendaciones preventivas.
<ul>
  <li>Revisión general.</li>
  <li>Control de peso.</li>
  <li>Orientación nutricional.</li>
  <li>Recomendaciones preventivas.</li>
</ul>

Lista de descripción dl

Una lista de descripción relaciona términos con sus respectivas definiciones mediante dt y dd.

Desparasitación
Tratamiento que elimina parásitos internos o externos.
Microchip
Dispositivo del tamaño de un grano de arroz con un código que identifica a la mascota. 
<dl>
  <dt>Desparasitación</dt>
  <dd>
    Tratamiento que elimina parásitos internos o externos.
  </dd>

  <dt>Microchip</dt>
  <dd>
    Dispositivo del tamaño de un grano de arroz
    con un código que identifica a la mascota.
  </dd>
</dl>

Enlaces

Enlace a otra página del sitio

Los enlaces internos permiten navegar entre las páginas de un mismo sitio utilizando rutas relativas.

Conoce nuestros servicios veterinarios 
<a href="servicios.html">
  Conoce nuestros servicios veterinarios
</a>

Enlace a un sitio externo

Un enlace externo dirige a un sitio diferente. target="_blank" permite abrirlo en otra pestaña y rel="noopener noreferrer" añade protección.

Visita el Ministerio de Desarrollo Agropecuario (se abre en otra pestaña) 
<a href="https://www.mida.gob.pa"
   target="_blank"
   rel="noopener noreferrer">
  Visita el Ministerio de Desarrollo Agropecuario
  (se abre en otra pestaña)
</a>

Enlace de descarga

El atributo download permite ofrecer un archivo para descargar, como una guía en formato PDF.

Descargar la guía de vacunación (PDF) 
<a href="assets/docs/guia-vacunacion.pdf" download>
  Descargar la guía de vacunación (PDF)
</a>

Enlaces de correo y teléfono

Los esquemas mailto y tel permiten iniciar el envío de un correo electrónico o una llamada desde un dispositivo compatible.

Correo: citas@consentidos.example

Teléfono: +507 9980-0000 

<a href="mailto:citas@consentidos.example">
  citas@consentidos.example
</a>

<a href="tel:+50799800000">
  +507 9980-0000
</a>

Imágenes y multimedia

Imagen con leyenda figure e img

figure agrupa una imagen con su leyenda. img incorpora el recurso gráfico y utiliza alt para describirlo. 

<figure>
  <img src="assets/img/luna.svg"
       alt="Ilustración de Luna, una gata gris atigrada, sentada"
       width="320"
       height="240"
       loading="lazy">
  <figcaption>Luna, paciente del mes.</figcaption>
</figure>

Buena práctica: alt describe la imagen para quien no puede verla. width y height reservan espacio, mientras loading="lazy" retrasa la carga de imágenes fuera de pantalla.

Audio

El elemento audio permite incorporar sonido en la página. controls muestra los controles de reproducción.

Tono de recordatorio de citas:

<p id="etq-audio">
  Tono de recordatorio de citas:
</p>

<audio controls preload="metadata"
       aria-labelledby="etq-audio">
  <source src="assets/media/recordatorio.mp3"
          type="audio/mpeg">
  Tu navegador no reproduce audio.
  <a href="assets/media/recordatorio.mp3">
    Descarga el tono
  </a>.
</audio>

Video con subtítulos

El elemento video permite reproducir contenido audiovisual. source ofrece formatos alternativos y track incorpora subtítulos. 

<video controls width="640" height="360"
       preload="metadata"
       poster="assets/media/consejos-poster.jpg">
  <source src="assets/media/consejos.webm"
          type="video/webm">
  <source src="assets/media/consejos.mp4"
          type="video/mp4">
  <track kind="subtitles"
         src="assets/media/consejos-es.vtt"
         srclang="es"
         label="Español"
         default>
  Tu navegador no reproduce video.
  <a href="assets/media/consejos.mp4">
    Descarga el video
  </a>.
</video>

Importante: abre esta página con Live Server para que el archivo de subtítulos WebVTT pueda cargarse correctamente.

Página propia incrustada con iframe

iframe permite mostrar otra página HTML dentro de la página actual. El atributo title describe el contenido incrustado. 

<iframe src="paginas/test.html"
        title="Página de prueba del sitio de ConSentidos"
        width="600"
        height="240"
        loading="lazy">
</iframe>

Mapa externo incrustado con iframe

iframe también permite insertar contenido de otros sitios, como un mapa. Se utilizan atributos de seguridad y privacidad para limitar sus permisos. 

<iframe
  src="https://www.openstreetmap.org/export/embed.html?bbox=-80.9950%2C8.0900%2C-80.9650%2C8.1100&amp;layer=mapnik"
  title="Mapa de Santiago de Veraguas, donde está la clínica"
  width="600"
  height="340"
  loading="lazy"
  referrerpolicy="no-referrer"
  sandbox="allow-scripts">
</iframe>

Seguridad: title describe el marco. sandbox limita los permisos del contenido externo y referrerpolicy="no-referrer" evita enviar la dirección de esta página al sitio incrustado.

Documento PDF con object

object permite insertar recursos externos, como documentos PDF. Su contenido interno funciona como alternativa si el navegador no puede mostrarlo. 

<object data="assets/docs/guia-vacunacion.pdf"
        type="application/pdf"
        width="600"
        height="400"
        aria-label="Guía de vacunación de ConSentidos, en PDF">
  <p>
    Tu navegador no muestra PDF.
    <a href="assets/docs/guia-vacunacion.pdf">
      Descarga la guía
    </a>.
  </p>
</object>

Elementos interactivos

Preguntas frecuentes con details y summary

details crea un bloque que el usuario puede abrir y cerrar. summary contiene el título visible del bloque. El atributo name permite agrupar preguntas para que se comporte como un acordeón.

¿Cada cuánto debo desparasitar a mi perro?

Cada tres meses, con la dosis que indique el veterinario.

¿Necesito cita para vacunar?

Sí. Así preparamos la vacuna y revisamos antes su carné. 

<details name="preguntas">
  <summary>
    ¿Cada cuánto debo desparasitar a mi perro?
  </summary>
  <p>
    Cada tres meses, con la dosis que indique el veterinario.
  </p>
</details>

<details name="preguntas">
  <summary>¿Necesito cita para vacunar?</summary>
  <p>
    Sí. Así preparamos la vacuna y revisamos antes su carné.
  </p>
</details>

Medidor meter

meter representa una medida dentro de un rango conocido. En este ejemplo muestra el peso de Luna frente a su rango saludable.

4,2 kg 4,2 kg (rango saludable: 3 a 5 kg) 

<p>
  <label for="peso-luna">Peso de Luna</label>
  <meter id="peso-luna"
         min="0"
         max="8"
         low="3"
         high="5"
         optimum="4"
         value="4.2">4,2 kg</meter>
  4,2 kg (rango saludable: 3 a 5 kg)
</p>

Recuerda: meter representa una medición dentro de un rango conocido. No debe confundirse con progress, que representa el avance de una tarea.

Barra de progreso progress y output

progress muestra el avance de una tarea que tiene un inicio y un final. output presenta el resultado o valor relacionado con ese progreso.

2 de 5 dosis 2 de 5 dosis 

<p>
  <label for="plan-vacunas">
    Plan de vacunación de Max
  </label>
  <progress id="plan-vacunas"
            value="2"
            max="5">2 de 5 dosis</progress>
  <output id="plan-texto"
          for="plan-vacunas">2 de 5 dosis</output>
</p>

<button type="button" id="btn-dosis">
  Registrar una dosis
</button>

<button type="button" id="btn-reiniciar" hidden>
  Reiniciar el plan
</button>

Nota: los botones funcionan mediante el archivo assets/js/componentes.js, incluido en el paquete base. Se utiliza type="button" para evitar que intenten enviar un formulario.
